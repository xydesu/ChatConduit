## 🌟 核心架構特色 (Core Highlights)

<CardGrid stagger>
  <Card title="⚡ 零指令頻道發言" icon="rocket">
    玩家無需輸入複雜指令，只需在聊天欄輸入前綴符號（如 `!` 發言至全服頻道，`$` 發言至商業頻道）即可自動路由訊息。
  </Card>

  <Card title="🧰 箱子 GUI 符號佈局" icon="setting">
    採用高度解耦的 **Symbol Map 符號地圖** 架構。管理員可在 `gui/*.yml` 中自由繪製選單，按鈕槽位動態解析，升級完全不破壞佈局。
  </Card>

  <Card title="📡 Redis 跨服 Pub/Sub 同步" icon="random">
    即時跨服聊天廣播、跨服私訊對接、好友連線/離線狀態即時推播，並搭配 Redis 記憶體快取維護全網在線玩家名冊。
  </Card>

  <Card title="🛑 全維度黑名單隱私保護" icon="shield">
    封鎖玩家時自動強制解除好友關係，並於本地與跨服維度完全屏蔽私訊與邀請。
  </Card>
</CardGrid>
