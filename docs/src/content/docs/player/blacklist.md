# 🎮 黑名單與隱私保護

如果您不希望受到某些玩家的騷擾，可使用黑名單功能保護您的遊玩體驗。

---

## 🚫 1. 加入黑名單 (`/friend block`)

執行指令：
```bash
/friend block <玩家名稱>
```

### ⚡ 自動執行的保護機制
1. **強制解綁好友**: 若對方原本是您的好友，系統會立即雙向刪除好友關係。
2. **清除申請紀錄**: 清除所有雙方發送且未處理的好友申請。
3. **完全屏蔽私訊**: 阻止對方發送本地與跨服私訊給您。
4. **屏蔽邀請**: 阻止對方邀請您加入玩家群組頻道。

---

## 🔓 2. 解除黑名單 (`/friend unblock`)

執行指令：
```bash
/friend unblock <玩家名稱>
```
亦可於 `/friend gui` 控制台的黑名單分頁中點擊頭顱解除封鎖。
