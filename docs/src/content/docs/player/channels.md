title: 🎮 零指令頻道發言與切換
description: 玩家如何使用前綴符號快速發言、切換頻道與訂閱官方頻道
---

在 ChatConduit 中，發言變得無比輕鬆簡單！您無需記住複雜的指令，直接在聊天欄輸入特定前綴符號即可發言至相應頻道。

---

## 💬 1. 零指令發言前綴 (Zero-Command Prefix)

直接在聊天欄輸入訊息前加前綴符號：

| 前綴符號 | 目標頻道 | 範例輸入 | 說明 |
| :--- | :--- | :--- | :--- |
| `!` | 全服廣播頻道 | `!大家好` | 訊息發送至全伺服器公共頻道 |
| `$` | 商業交易頻道 | `$出售神裝` | 訊息發送至買賣交易頻道 |
| `@` | VIP 專屬頻道 | `@VIP朋友好` | 發送至 VIP 專屬頻道（需權限）|

---

## 🔄 2. 頻道切換指令 (/channel switch)

若您想將預設發言頻道固定在特定頻道：

```bash
/channel switch trade
```
切換後，直接在聊天欄輸入文字（無前綴）將會預設發言至商業頻道！

---

## 🔕 3. 頻道訂閱與開啟/關閉 (/channel toggle)

若您不想接收商業頻道的訊息：
```bash
/channel toggle trade
```
即可取消訂閱該頻道。再次輸入即可重新開啟訂閱！
