ChatConduit 提供強大的社交好友系統與零指令 GUI 箱子控制台。

---

## 好友指令一覽 (Command Overview)

| 指令 | 說明 |
| :--- | :--- |
| `/friend add <玩家>` | 發送好友申請（防刷申請 CD 為 5 秒） |
| `/friend accept <玩家>` | 接受來自對方的申請 |
| `/friend deny <玩家>` | 拒絕來自對方的申請 |
| `/friend revoke <玩家>` | 撤回已發出的好友申請 |
| `/friend remove <玩家>` | 刪除好友關係（雙向解綁） |
| `/friend list [頁碼]` | 檢視好友列表（包含在線狀態與伺服器位置） |
| `/friend block <玩家>` | 將目標加入黑名單 |
| `/friend unblock <玩家>` | 解除黑名單封鎖 |
| `/friend gui` (或 `/f`) | 開啟箱子 GUI 社交控制台 |

---

## 箱子 GUI 選單操作說明

輸入 `/friend gui` 或短指令 `/f` 即可開啟 UI 選單：
- **個人頭顱**: 展示個人頭像、總好友數與當前頻道。
- **好友列表 (`/f list`)**:
  - **左鍵點擊好友頭顱**: 快速填入 `/msg <好友>` 發送私訊。
  - **右鍵點擊好友頭顱**: 開啟好友二級管理選單（刪除好友 / 檢視資訊）。
- **待處理申請**: 一鍵點擊 `[綠色翡翠]` 接受申請，或點擊 `[紅色紅石]` 拒絕。
- **即時 UI 刷新**: 好友上線或離線時，UI 畫面由系統自動實時刷新，不需手動關閉重新開啟！
