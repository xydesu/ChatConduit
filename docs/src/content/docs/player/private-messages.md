title: 🎮 跨服私訊與快速回覆 (/msg)

---

不論好友是在同一個分服還是在其他子伺服器（例如生存服、建築服），您都可以即時與對方發送私訊！

---

## ✉️ 私訊指令 (Private Messaging Commands)

* **發送私訊**:
  ```bash
  /msg <玩家名稱> <訊息>
  ```
  *(簡寫別名支援: `/tell`, `/w`)*

* **快速回覆**:
  ```bash
  /r <訊息>
  ```
  *(快速回覆最後一位與您私訊對話的玩家)*

---

## 💬 訊息視覺效果範例

- **您看到的視角**: `[我 -> Alex(survival-1)] 待會要去打副本嗎？`
- **對方看到的視角**: `[Alex(survival-1) -> 我] 待會要去打副本嗎？`

---

## 🛡️ 隱私安全過濾
- 若對方將您加入黑名單，私訊將無法發送並提示對方拒收訊息。
- 若您被管理員禁言 (`/mute`)，將無法發送私訊。
